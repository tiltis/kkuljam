# 꿀잠

대구 북구 수면건강 리빙랩 〈꿀잠의 비결〉(2026)에서 푸린의노래 팀이 만들고 있는 수면 습관 앱 시제품입니다.

잠이 부족한 사람은 쉽게 예민해집니다. 그래서 이 앱은 손으로 적는 일을 거의 없앴습니다. 수면 시각은 스마트워치 기록을 가져오고, 사용자는 아침에 기분 하나만 고릅니다. 앱은 지난 일주일 기록을 보고 근거가 있는 방법 하나를 골라 7일 동안 해 보자고 제안한 뒤, 시작 전과 비교해 결과를 알려 줍니다.

치료 앱이 아닙니다. 진단하지 않고 약에 대해 조언하지 않습니다.(중요) 그럴 권한도 없음;

## 실행

`앱_웹시제품/index.html`을 브라우저로 열면 됩니다. 따로 설치할 것은 없고, 글꼴만 인터넷에서 불러옵니다.

화면 속 방의 물건이 곧 메뉴입니다. 창문을 누르면 이번 주 잠든 시각, 벽 메모는 이번 주에 해 볼 것, 책 선반은 잠 안 올 때 쓰는 DBT 기술, 램프는 밤에 깼을 때, 휴대폰은 수면 데이터 연결, 침대는 어젯밤 기록입니다. 협탁 위 시계는 발표용으로 시간대를 바꿔 보는 버튼입니다.

기록은 브라우저 안에만 저장됩니다. 주소 끝에 `?t=night`처럼 붙이면 시간대를, `?o=memo`처럼 붙이면 특정 화면을 바로 열 수 있습니다.

## 수면 데이터

웹 페이지는 삼성 헬스 데이터를 직접 읽을 수 없습니다. 삼성 헬스 Data SDK와 헬스 커넥트가 안드로이드 기기 안에서만 동작하기 때문입니다. 그래서 시제품은 예시 데이터를 쓰거나, 삼성 헬스에서 내려받은 수면 CSV 파일을 불러옵니다. CSV 형식은 아직 실제 파일로 확인하지 못했습니다. 앱으로 만들 때는 헬스 커넥트로 자동 연결할 계획입니다.
